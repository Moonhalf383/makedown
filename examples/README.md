# Markfile 示例项目

`valid/` 保存能够构建健康依赖图的项目，每个项目的 `expected.txt` 指定起始目标。

`invalid/` 保存诊断场景，每个项目的 `expected.txt` 指定起始目标和必须出现的诊断代码。

[`templates/`](templates/README.md) 提供从单目标简报到流水线交接手册的五份中文编译模板，附带对应项目、运行命令与检查方式。

元数据格式如下：

```text
start=模块路径::目标名
codes=E001,P001
```

根模块目标只写目标名。诊断代码列表表示必须出现的代码，不限制额外的级联诊断。
